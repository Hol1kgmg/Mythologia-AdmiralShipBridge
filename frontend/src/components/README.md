# UI コンポーネントライブラリ (shadcn/ui)

`src/components/ui/` ディレクトリには、shadcn/ui ベースの44個の共通UIコンポーネントが配置されています。

## 🎨 利用可能なコンポーネント一覧

### 🗂️ レイアウト・構造系コンポーネント (8個)

| コンポーネント | 用途 | 主要機能 |
|---------------|------|----------|
| **Card** | コンテンツのグループ化(shared/boxと同じ) | Header, Title, Description, Content, Footer対応 |
| **Separator** | 視覚的分離 | 水平・垂直の区切り線 |
| **AspectRatio** | アスペクト比維持 | 画像・動画の縦横比固定 |
| **ResizablePanel** | 可変サイズ領域 | ドラッグでリサイズ可能な領域 |
| **ScrollArea** | スクロール領域 | カスタムスクロールバー付きエリア |
| **Sheet** | スライドパネル | 画面端からスライドするパネル（4方向対応） |
| **Sidebar** | サイドバー | アプリケーション用（折りたたみ・モバイル対応） |
| **Skeleton** | ローディング表示 | コンテンツ読み込み中のプレースホルダー |

## ✨ 技術的特徴

全コンポーネント共通の特徴：

- **🎯 アクセシビリティ**: Radix UI プリミティブによる高いアクセシビリティ
- **🎨 デザインシステム**: shadcn/ui による統一されたデザイン
- **🛡️ 型安全性**: TypeScript による完全な型サポート
- **⚡ パフォーマンス**: "use client" による適切なクライアントコンポーネント実装
- **🎭 カスタマイズ**: Tailwind CSS によるスタイルカスタマイズ
- **📱 レスポンシブ**: モバイルファーストなレスポンシブデザイン

## 🚀 基本的な使用方法

```tsx
// 単一コンポーネントのインポート
import { Button } from "@/components/ui/button"

// 複数コンポーネントのインポート
import { Card, CardContent, CardDescription, CardHeader, CardTitle } from "@/components/ui/card"

// 使用例
export const ExampleComponent = () => {
  return (
    <Card>
      <CardHeader>
        <CardTitle>タイトル</CardTitle>
        <CardDescription>説明文</CardDescription>
      </CardHeader>
      <CardContent>
        <Button variant="default" size="default">
          ボタンをクリック
        </Button>
      </CardContent>
    </Card>
  )
}
```

## 💡 重要なインポートルール

- **エイリアス必須**: `@/components/ui/` プレフィックスを使用
- **直接インポート**: 各コンポーネントファイルから直接インポート
- **バレルファイル禁止**: `index.ts` を経由したインポートは使用しない

```tsx
// ✅ 正しいインポート
import { Button } from "@/components/ui/button"
import { Input } from "@/components/ui/input"

// ❌ 間違ったインポート（相対パス）
import { Button } from "../../ui/button"

// ❌ 間違ったインポート（バレルファイル）
import { Button, Input } from "@/components/ui"
```
